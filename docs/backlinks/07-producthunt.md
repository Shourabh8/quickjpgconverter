## Tagline
Free image converter that runs entirely in your browser — no uploads, no accounts, 100% private.

## Description

Quick JPG Converter is a free, privacy-first image converter that processes all files locally in your browser using WebAssembly and Canvas API. Your images never leave your device.

**Why it's different:**
Most online converters upload your files to their servers. Quick JPG Converter does everything client-side — faster conversion, complete privacy, and no file size restrictions.

**Features:**
- Convert between JPG, PNG, WebP, HEIC, BMP, AVIF, SVG
- Batch conversion with quality control
- Compress to specific file sizes (100KB, 200KB, custom)
- AI background removal (runs in-browser)
- Resize, crop, enhance images
- Passport photo sizing for 50+ countries
- PDF operations (PDF to JPG, JPG to PDF)
- EXIF metadata removal
- Base64 encoding

**Built with:**
- Astro 5 (SSG)
- WebAssembly + Canvas API
- ONNX Runtime for AI features
- Cloudflare Pages
- Tailwind CSS v4

**Perfect for:**
- Photographers processing client work
- Designers optimizing assets
- Anyone who values privacy
- Web developers optimizing images for Core Web Vitals
